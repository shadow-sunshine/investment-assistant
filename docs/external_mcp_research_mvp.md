# 联网投研 MVP：MCP 外部数据阶段

## 目标

把投研助手从“本地官方年报问答器”扩展为“本地证据 + 外部结构化数据”的受控投研助手：

- 本地官方资料用于可追溯年报/公告原文和字段锚点；
- MCP/结构化数据用于最新行情、历史市场观察和第三方财务候选；
- 两者不混淆：第三方结果可用于分析，但不能冒充官方年报核验结论。

## 已接入链路

聊天请求在第三方数据模式下：

```text
用户问题
  -> 会话任务识别
  -> 本地公司清单命中 / MCP 外部候选发现
  -> MCP 行情快照或结构化财务调用
  -> 结果解析、来源与抓取时间绑定
  -> 第三方候选答案 + 限制说明
```

本阶段代码：

- `investment_assistant/mcp_research.py`
  - 识别行情/最新问题；
  - 格式化行情结果；
  - 保留 source、retrieved_at、provenance；
  - 明确 `third_party_market_data` 和 `verified=false`。
- `investment_assistant/chat_session.py`
  - MCP 模式行情问题优先走行情工具，不再误走财务字段；
  - MCP 模式未知公司允许外部候选发现；
  - 外部失败不回退到官方旧年报。
- `investment_assistant/api.py`
  - 对话链路绑定市场快照工具；
  - MCP 模式显式启用外部候选发现；
  - 仍由服务端身份、工具白名单和审计账本控制。

## 两个 MCP 的职责

- AKShare MCP：港股/A股/美股行情快照、行情数据、结构化财务表和公司候选发现。
- BaoStock MCP：A股结构化财务候选和受限公司数据能力。

实际是否可用取决于运行环境配置：

```text
IA_MCP_ENABLED=1
IA_AKSHARE_MCP_PYTHON=...
IA_AKSHARE_MCP_URL=http://127.0.0.1:28888/mcp
IA_BAOSTOCK_MCP_PYTHON=...
```

`start_demo.py` 会在启动前检查两个 MCP 运行时和 AKShare MCP 配置；未配置时拒绝启动，不伪造“已连接”。

## 用户可得到的结果

### 最新行情

例如：

```text
腾讯最新股价和涨跌幅
```

系统会返回：

- 最新价/收盘价（如果来源提供）；
- 涨跌幅、成交量、数据日期（如果来源提供）；
- 来源名称、抓取时间和工具 provenance；
- “第三方结构化数据，不是官方年报核验结论”的明确说明。

### 结构化财务候选

例如：

```text
阿里巴巴 2025 年收入
```

MCP 模式下可以返回第三方财务候选；币种、单位、期间和字段缺失时不得补猜，结果标记为候选，不自动升级为官方结论。

### 外部公司发现

MCP 模式下未收录公司可以调用外部候选源识别市场和证券代码。识别结果只是导航候选，后续仍需要：

- MCP 候选数据，或
- 官方资料发现/入库/字段核验。

## 当前边界

本阶段**没有**宣称：

- MCP 返回的内容是实时保证；
- 外部候选等于官方公告；
- 没有配置 MCP 时可以访问互联网；
- 本地索引自动包含官网刚发布的全部资料；
- 任意公司都能立即回答所有指标。

官方公告自动发现/下载/入库仍是独立链路；MCP 结构化数据和官方文档证据必须在回答中分区展示。

## 验收

离线验证：

- 行情请求优先调用行情工具；
- MCP 失败不回退官方旧年报；
- 公司候选允许外部发现但不提升证据等级；
- source/retrieved_at/provenance 保留；
- 多轮会话和用户画像不被 MCP 结果污染。

真实外部验证需要在本机启动 MCP 并使用真实配置；没有执行过的 live smoke 不写成通过。
