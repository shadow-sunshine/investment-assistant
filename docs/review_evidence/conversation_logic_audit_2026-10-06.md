# 对话业务逻辑审计与修复：2026-10-06

## 范围与诚实结论

用户提供了真实失败截图：
- “我想查看港股公司的最新公告”被当成上一家公司的财务查询。
- “腾讯最新官方资料有哪些？”被要求先选年度/指标，随后又被主体校验拒绝。
- “收入和净利润”只回答收入。
- “我偏保守，主要看港股”之后文字确认显示没有待确认内容。
- “我想了解最近的港股”沿用腾讯和 2025 年。

本次不是只核对测试计数，而是从 `/api/conversations/{id}/turns` 开始，以临时数据库/独立身份运行真实对话编排、真实本地官方文件和字段服务。禁止付费模型、外部 MCP 与报告生成联网。

第一批 24 条业务验收用例在修复前 **23 failed / 1 passed**。这说明原有 902 passed 不能证明自然对话可用：之前不少测试只验证存储/函数/固定 fake 回答，没有验证用户点击后经过所有业务层的语义。

本轮共归纳并修复 **12 类缺陷**（类别不是代码行数，也不表示全系统只剩/总共有 12 个漏洞）。不能证明任意自然语言没有漏洞，更不能把本地文档目录说成实时官网全量信息。

## 12 类缺陷与处理

| 编号 | 缺陷 | 修复契约 |
|---|---|---|
| 1 | 资料目录查询被当成财务字段查询，强制先问年份/指标 | 新增任务契约，目录按本地已验证文档元数据列表回答，不需要全文包含“有哪些” |
| 2 | 广义港股/A股/美股请求继承上一家公司 | 清理不适用财务范围，再澄清公司/行业/市场走势，不把市场词当成腾讯财务主体 |
| 3 | 闲聊、产品使用与财务概念继承旧年度 | 产品/概念问答在金融槽位补全前处理，使用原问题，不注入年报年度 |
| 4 | “最新”被旧 year/knowledge_year 再次改写；生产 adapter 未接新覆盖错误码 | 最新意图清理本轮旧期间；实际 conversation adapter 接官方覆盖状态与原文检索 |
| 5 | 多指标提问只响应首个收入字段 | 通过整句主体门禁后拆解每项指标，返回 metric_results；全部有核验才 answered，否则 partial/明确缺口 |
| 6 | 利息收入/服务收入/净收入可错误使用总收入锚点 | 总收入锚点只接受总收入意图，其他字段单独查证据或标缺口，不能伪装成已核验数值 |
| 7 | “都要”不绑定上一轮指标选择项，裸年份/补充指标误进公司发现 | 保存 pending_metric_options，绑定当前槽位解析选择；有效查询显式携带已确认的公司和期间 |
| 8 | UI 确认按钮已写画像，再输入“确认”却显示无待确认 | 会话保存确认候选 ID；仅在同会话、候选已确认且值仍有效时解释“已保存”，不重复写入 |
| 9 | 未确认候选复制到 session_preferences，取消或停用后还套用旧策略 | 待保存候选与已确认画像/用户明确临时偏好分离；取消不生成策略提示，停用长期偏好真正生效 |
| 10 | “换成阿里巴巴”可能被画像更新正则抢占 | 画像修改需要明确偏好字段；换公司清旧证据/期间，再走公司发现与澄清 |
| 11 | 主体语法词通过 set 随机顺序逐项删除，导致“官方披露清单”等被随机误判 | 一次最长词匹配删除已知语法片段，确定性解析，同时保持未知公司拒绝/澄清 |
| 12 | 目录/意图阶段异常发生在已有异常处理外，用户请求挂为处理中 | 业务前置阶段失败也持久化中文失败回复，允许重试，不输出内部异常正文 |

## 改动与分层

- `investment_assistant/question_intents.py`：目录/市场/产品/财务/年份/选择项任务契约及多指标解析。
- `investment_assistant/conversation_memory.py`：任务先行、状态隔离、有效查询、画像生命周期与异常结束。
- `investment_assistant/official_document_answers.py`：独立官方文档目录能力；按披露日期列来源、期间、索引时间和 SHA，明确 local_snapshot。
- `investment_assistant/company_qa.py`：多指标逐项回答、严格总收入锚点意图和确定性主体语法解析。
- `investment_assistant/api.py`：生产聊天 adapter 接入目录能力和官方覆盖状态，原有权限校验保持。
- `investment_assistant/user_profile.py`：偏好命令与公司切换分离，中文字段/值显示。
- `investment_assistant/research_answer.py`：财务概念常见表达“是什么意思”支持。
- `investment_assistant/chat_session.py`：partial/目录状态标签不冒充完整核验。
- `investment_assistant/web_app.py`：研究偏好确认和查看使用中文名称/值。
- `tests/test_conversation_behavior_acceptance.py`：新增 54 条行为验收，真实 HTTP 业务链路、真实本地官方资料，以及 Streamlit AppTest → 真实 FastAPI 联合交互。
- `tests/test_company_qa.py`、`tests/test_conversation_store.py`：对应目录/有效查询契约更新；不是删除失败测试。

新增任务契约仍是**有边界的规则解析**，不是宣称已经接入通用 LLM 语义理解。它解决“错路由/错继承/答漏项”，不解决不存在的数据和所有未知表达。

## 修复后的关键实际行为

### 查询目录

“腾讯最新官方资料有哪些？” → documents_listed：
- 已入库的 HKEX Next Day Disclosure Return，资料年度 2026。
- 已入库的 HKEX ANNUAL REPORT 2025，报告年度 2025。
- 显示披露时间、入库时间、一手来源链接。
- 明确“本地已入库目录，本轮未检查官网，不保证官网最新全部披露”。

### 不完整市场问题

“我想查看港股公司的最新公告” → 询问哪家公司；随后只说“腾讯” → 返回目录，不再强制选 2025 年。
“我想了解最近的港股” → 澄清市场走势/行业/公司，并说明当前全市场行情未覆盖；不沿用腾讯的财务问题。

### 多指标

“腾讯 2025 年收入和净利润怎么样？” → 每项分别回答：收入用核验锚点；利润可用官方原文摘录或明确未核验，不能把收入的 answered 当成两项全部完成。
“腾讯 → 2025 → 都要” → 显式查询收入、净利润、经营现金流，各项标明证据状态。

### 用户画像

“我偏保守，主要看港股” → 中文候选、明确确认；取消后不继续附加保守策略。
UI 点击确认后再输入“确认” → 提示已保存，不虚构候选丢失。
“本次不使用长期偏好” → 停用长期策略组织，保留用户另外明确提出的临时偏好。

## 未完成或不能承诺的边界

- 不保证任意自然语言都能理解；新的复杂业务场景仍需验收。
- 没有执行官网实时刷新或新文档自动入库，不宣称获得全市场实时一手资料。
- 字段未核验的官方摘录不自动升级为财务结论，多指标结果允许 partial。
- 没有使用付费 LLM 或外部 MCP 做 live smoke；本轮证明的是本地真实业务接线与证据边界。
- UI 联合测试使用 Streamlit AppTest，不代替真实浏览器的宽屏/窄屏视觉验证。

后续验收应按真实用户任务成功率、澄清合理性、字段覆盖、确认状态一致性与数据时效评价，不再只以“全部单元测试通过”作为产品可用证明。
