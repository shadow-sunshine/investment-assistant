## R6/R7 accepted deployment boundaries（2026-09-27）

- 团队身份是单机服务端 token 映射，不是企业 SSO/IdP；需运维配置凭证与可选到期时间，只支持一个 API worker。JSON 记录、审计和进程锁不防具有本地文件/环境配置权限的管理员，不可宣称外部不可篡改。
- 完整 claim 集由审核人手工登记、逐条核验与覆盖声明；没有自动完整抽取或通用语义蕴含证明。真报告未完成人工覆盖仍待审，不能用 fixture 全绿称为零幻觉。KI-001/KI-002/KI-003 的冻结边界未解除。
- 版本关注只做固定白名单本地资料/已发布版本的显式检查，不是自主联网研究或定时新增披露抓取；研究记忆仅为有限期用户注记，不作为事实证据。真实网络总预算、市场数据授权、生产并发、OCR 与检索切流仍不在本批次验收范围。KI-006 未关闭，R3 的 no_online_ab 不因团队治理完成而解除。
